LINUX
SIMPLE COMMANDS
$ date  --> display date
$ cal   --> display calendar
$ df    --> free space disk drives
$ pwd   --> current directory

$ ls    --> listing the contents of a directory
$ ls -a --> listing the contents of a directory and hidden files
$ ls <directorioA> <directorioB> -> list multiple directories

$ cd    --> changing the working directory
$ cd -  --> change to the previous directory
$ cd ~  --> change to the home directory
$ cd ~[user-name]   --> change to the indicated user directory

EXPLORING THE SYSTEM

$ ls						--> content directory
$ ls [name-directory]/				--> list directory files
$ ls [name-directory] [name-directory]		--> list many directories you want
$ ls -l 					--> content directory in list way
$ ls -t						--> muestra los archivos de acuerdo a su fecha y tiempo de creación
$ ls -lt --reverse			
$ ls -lt -r					--> muestra los archivos de acuerdo a su fecha de mas viejos a mas nuevos
$ file [nombre-directorio|nombre-archivo]	--> te muestra el tipo de archivo que es
$ less [archivo-texto]				--> muestra contenido de archivos de texto
cp                          --> copia archivos
mv                          --> mueve archivos o cambia de nombre los archivos o directorios

rm <fileNAme>                       --> elimina un archivo, para folder se usa otra opcion
rm -i <fileName>                    --> elimina un archivo, con al diferencia que te va preguntando y enseñando todo el proceso de borrado del archivo
rm -r <directory>                   --> elimina directorios, subdirectorios y archivos
